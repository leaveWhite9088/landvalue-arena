# 地价沙盘

用专业街和建筑光环把一块块地价抬上去。这是给大模型的空间规划基准：模型不看画面，只通过 MCP 读盘、放置、拆除。人负责开局，模型负责把地价做高。

![地价沙盘](landvalue-main.jpeg)

## 怎么当成基准

一局就是一份方案：当前盘面，加上累计花费。模型只能做五件事：

1. 查专业街词典
2. 看可放置的建筑
3. 看地图
4. 放置一座建筑
5. 拆除一座建筑

不能改建筑表、专业街、棋盘数量、棋盘尺寸或优化优先级。那些是出题人的配置。地价由服务端算好，放在每次调用的返回里。模型不要自己复利，也不要按格把一座建筑拆成多座。

比较两份方案时，按当前优先级做字典序比较。默认顺序是：

1. 总地价最高
2. 最高地价最高
3. 总重复次数最少
4. 累计花费最少

前两项越大越好，后两项越小越好。先比第一项，持平再比下一项。同一终盘，拆过再放的方案花费更高，因而更差。若把花费调到第一位，什么都不放会赢过任何付过钱的方案。

## 棋盘

最多 4 块，每块行数和列数独立。默认是 3×3、4×4、3×4、5×5。记法是行×列，所以 3×4 是 3 行 4 列。

坐标是三元组 `(board, row, col)`，三个数都从 1 计。`board` 是棋盘编号，按当前列表顺序，不是建筑的标识。删除中间的棋盘会把后面的编号前移，放置前要重新看地图。

每格可以单独禁用。启用格的基础地价是 100。禁用格没有地价，也不能放建筑。不要求放满。空着的启用格仍以 100 计入总地价，也能吃光环。

占用、禁用、固有光环、专业街的成街和光环都不跨棋盘。同一条街可以在不同棋盘上各自生效一次。总地价、最高地价、重复次数、花费、占地是全部棋盘合计。重复按类型在全部棋盘上的座数算，不按棋盘分开。

## 建筑

每种类型无限供应，可以重复放置。名称可以重复，引用一律用标识。形状只有四种，记作宽×高，宽是列方向，高是行方向：

- 1×1
- 2×1：两列、一行
- 1×2：一列、两行
- 2×2

两格建筑放置时可以旋转 90°，宽高互换。1×1 和 2×2 旋转无意义。一座建筑是一次放置：一座 2×2 是一座，不是四座。

锚点是该棋盘上占地左上角，也就是行号、列号都最小的那一格。占地必须全部落在这块棋盘的启用空格上，否则整次拒绝，不扣费，盘面不变。

## 专业街

每条街有名称、恰好 3 个建筑类型、一个正的加成百分比。三个类型可以重复，例如 A+A+B。类型被删掉之后，引用它的街不再生效。

成街按座、按连通簇判定，不按格：

- 只看类型属于这条街、并且在同一块棋盘上的建筑。
- 两座候选建筑八邻接，当且仅当其中一座的某一格与另一座的某一格横、竖或斜向相邻。光环重叠不算相邻。不属于这条街的建筑不能把两座候选建筑连起来。不同棋盘上的建筑永不相邻。
- 一座建筑是一个节点，不把占地拆成多座。一座 2×2 的 A 只算 1 座 A。
- 簇内座数满足组合要求时，这条街在这个簇生效一次。A+A+B 需要至少 2 座 A 和 1 座 B。多出来的座不会让它再生效一次。
- 互不连通的簇各自判定。同一条街的不同簇、以及不同棋盘上的簇，都可以各自生效一次。

生效时，簇内每一座属于该街类型的建筑都是参与建筑。同一座建筑可以同时参与多条街。

## 地价

两种加成，都是乘法叠加。

```
地价 = 100 × (1 + p₁) × (1 + p₂) × … × (1 + pₙ)
```

### 建筑自己的固定加成

每座建筑对自身占地和周围的启用格施加一笔固有加成，与专业街无关：

- 1×1 → 10%
- 1×2 / 2×1 → 20%
- 2×2 → 30%

范围是占地向外扩一格，含自身占地。1×1 的周围是 8 格，加上自身共 9 格；2×1 的周围是 10 格，加上自身共 12 格。边上会被棋盘边界裁掉。其他棋盘上的格子吃不到。

每座只施加一次，不按占地格数连乘。自身那几格也只吃到这一次。两座建筑的范围都盖到同一格时，该格吃到两笔。

### 专业街

一条街在一个簇里生效时，光环是簇内每一座参与建筑的占地向外扩一格（含自身占地）的并集。参与建筑自己占的格子也吃到这一次，不会因为是自己的格子而排除。

同一簇对同一格只施加一次该街的加成，不论有几座参与建筑盖到它。不按座连乘，也不按格连乘。不同的街各算各的。同一条街的不同簇也各算各的：两个簇都盖到同一格时，该格吃到两次。

空着的启用格同样吃光环。没有被任何加成盖到的启用格，地价是 100。

一座 1×1 单独放着，自身那格是 100 × 1.1 = 110。它若再参与一条 20% 的街，自身那格是 100 × 1.1 × 1.2 = 132。另一格被两座 1×1 的范围盖到，又被一条 20% 的街生效一次，是 100 × 1.1 × 1.1 × 1.2 = 145.2。同一条街再多一座参与建筑盖过来，仍然只乘这一次 1.2。

## 花费

没有预算上限。只在放置成功时增加，增加量是该类型当时的造价。之后改造价，不改写已经发生的花费。拆除不退钱。拆除后再放，按新的一次放置重新计费。

重复次数只看当前场上的座。某类型有 k 座，重复次数是 k − 1。总重复次数 = 场上座数 − 用到的不同类型数。花费只看历史，不看场上还剩哪些。

## 容易算错的地方

- 按座计，不按格。2×2 是一座。
- 坐标是 `(board, row, col)`，不是 `(row, col)`。
- 光环和成街不跨棋盘。
- 建筑自身占的格子也吃固有加成，也吃专业街。
- 同一条街在同一个簇里，对同一格只乘一次。
- 拆除不退钱。重复只看还在场上的，花费只看曾经付过的。
- 不要自己算地价。用工具返回的数字。
